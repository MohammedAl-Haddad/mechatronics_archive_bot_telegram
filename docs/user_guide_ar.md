# دليل المستخدمين

يحتوي البوت على أدوات خاصة بالمشرفين لإدارة المحتوى والمستخدمين. إذا كنت تملك صلاحيات مناسبة أو كنت مالك البوت فيمكنك فتح واجهة إدارة المشرفين من خلال الأمر `/admins` داخل المحادثة الخاصة أو زر "👤 إدارة المشرفين" في قائمة البداية.

المستخدمون العاديون لا يرون هذا الزر ولا يمكنهم الوصول إلى تلك الواجهة.
